# 10 — Contributing

## 1. Як додати нову модель інвертора
1. Зібрати реальний JSON-відповідь (анонімізувати серійні).
2. Додати у `tests/fixtures/local_typeX.json`.
3. Додати декодер у `models.py` (індекси з дослідження).
4. Додати golden test у `test_models.py`.
5. Оновити docs (03-data-model, 11-troubleshooting).
6. PR з описом моделі, firmware, тестами.

## 2. Як додати нову сутність
1. Додати поле в `SolaxData`.
2. Додати entity description у відповідній платформі.
3. Додати toggle у entity groups (опційно).
4. Оновити 03-data-model.md.
5. Тест.

## 3. Як додати новий метод підключення
1. Реалізувати `api/base.py` інтерфейс.
2. Додати гілку в config flow + options.
3. Тести клієнта.
4. Документація 02-connection-methods.

## 4. PR-процес
- Fork → branch → PR.
- CI має бути зеленим.
- Опис: що, навіщо, як тестували.
- Code review від мейнтейнера.

## 5. Стиль коду
- ruff (формат + лінт).
- Type hints де можливо.
- Докстрінги для публічних функцій.
- Українська/англійська в коментарях — на розсуд, але послідовно (код англійською).

## 6. Звіт про баги
